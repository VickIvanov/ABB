# Вступление и описание решения

Проект `ABS tender` - веб-приложение для удобной работы с выборками данными по закупкам. Приложение позволяет проводить аналитические исследования на основе собранных и регулярно обновляемых данные о гос. закупках и их исполнителях с сайта https://zakupki.gov.ru. Пользователями решения являются сотрудники банка: в первую очередь аналитики и те, кто планирует развитие продукта - в плане его маркетинга и продвижение. Также пользователями приложения являются продавцы - для них система представляет собой CRM, они имеют возможность получать в удобном интерфейсе контактные данные актуальных победителей на текущий день и рекомендации по предсказанным ИИ будущим победителям тендеров.
Основной задачей проекта является получение данных с сайта гос.закупок, размещение их в заранее спроектированную реляционную базу данных в PostgreSQL и возможность для пользователя удобно выгружать данные по требуемым срезам.

Преимуществом проекта перед сайтом гос.закупок является решение следующих сложностей в текущей работе пользователей:

1) Крайне низкое удобство сайта в получении различных выборок и неочевидность их компоновки, т.к. требуемые данные размещены в различных разделах сайта;

2) Сайт гос.закупки, будучи спроектирован под более низкие нагрузки и минимальную архитектуру, сильно тормозит при работе;

3) С этого сайта невозможно выгрузить информацию для дальнейшей аналитики и построения предикативных моделей.

Данный проект успешно решает все эти задачи.

Стек проекта: PostgreSQL, Python (Sklearn, Tensorflow, Flask), VueJS, Docker.

У нас есть [***рабочая MVP-версия (минимально работоспособная версия продукта)***](http://178.154.232.207), которая не только обладает удобным интерфейсом, но достаточным функционалом, чтобы провести анализ несложной модели. Мы запустили ее на [внешнем сервере](http://178.154.232.207). Данные для входа - `admin`/`admin`.

# Техническое описание проекта
## Установка
Т.к. в проекте используется микросервисная архитектура, большая часть сервисов доступна для скачивания в виде контейнеров.

Важно, что у вас должен быть установлен и запущен `Docker`.

> После того, как установка всех необходимых зависимостей будет выполнена, вы сомжете потестировать систему локально по ссылке http://localhost/

## Требования

- Установить [Docker](https://www.docker.com/products/docker-desktop)
- `git clone https://github.com/VickIvanov/ABB.git`

## Запуск сервера

Перейти в папку проекта:

```bash
docker-compose build
docker-compose up -d
```

Открываем наше приложение: [http://127.0.0.1](http://127.0.0.1)

Для разработки дополнительно доступен прямой доступ к бекенду и БД

- postgre: 127.0.0.1:5432
- pgadmin: 127.0.0.1:5000

## Остановка сервера

```bash
docker-compose down
```
